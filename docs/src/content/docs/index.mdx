Write a query once with a typed, immutable builder. Compile it for Lomkit, PocketBase or Strapi with one function call.

```ts
import { query } from 'dialectr'
import { toPocketbase } from 'dialectr-adapter-pocketbase'

query<{ age: number }>().where('age', '>=', 18).limit(20).to(toPocketbase)
```

## Build once, compile by dialect

| Builder | Dialects included |
|---|---|
| Typed filters, groups, relations and pagination | Lomkit, PocketBase and Strapi |
| Neutral, validated query representation | Independent adapter packages |
| Zero runtime dependencies in the core | Your transport remains your choice |
